# Aiming Cookie

**本地运行的 FPS 瞄准 AI 教练。** 面向 KovaaK's FPS Aim Trainer 的认真训练者：打完一局，它已经看完了你的鼠标轨迹、击杀记录和录像，能告诉你哪里出了问题、偏了多少度、下次练什么。

不打分、不玄学、不上云——所有证据来自你自己的机器。

---

## 为什么做这个

市面上的瞄准工具只有两种：**数据面板**（给你 KPS/命中率，但不说为什么）和**感觉派教学**（说得出为什么，但看不到你的数据）。

Aiming Cookie 的立场是：**教练必须先看证据，再开口。** 它把一局训练拆成四路证据，用确定性管线测量、用视觉管线"看"靶子，最后让大模型教练拿着这些事实讲课——每一句判断都能追溯到具体数据，讲不到的就是不知道。

## 它怎么工作

```
你打一局 KovaaK
      │  （全自动，无需任何操作）
      ▼
┌─────────────────────────────────────────┐
│  四源证据采集                             │
│  Stats 击杀表 · Performance 计数 ·        │
│  Raw Input 鼠标轨迹(1ms) · 窗口录像       │
└─────────────────────────────────────────┘
      ▼
┌─────────────────────────────────────────┐
│  确定性分析 + 通用视觉 CV                  │
│  运动学指标 · 靶子检测 · 击中判定 ·        │
│  偏移向量 · 转火节奏 · 跟靶误差            │
└─────────────────────────────────────────┘
      ▼
┌─────────────────────────────────────────┐
│  AI Coach 讲解                           │
│  读真实数据 → 指出问题 → @ 视频片段        │
│  → 给训练建议 → 记录进步                  │
└─────────────────────────────────────────┘
```

## 核心能力

### 🎯 全自动证据采集

打完即得，不需要手动导入任何文件：

- **KovaaK 三源自动摄取**：Stats 击杀表、Performance 计数、挑战窗口，随局自动入库
- **Windows Raw Input**（opt-in 授权）：1ms 采样率的真实鼠标信号——不是游戏内插值的近似值
- **窗口录像**：自动录制本局画面，与分析时间轴像素级对齐
- **不可信数据不入库**：源文件指纹校验，改过一个字节都会被发现

### 👁️ 通用视觉分析（本项目的主打差异点）

计算机视觉管线让 Coach 从"只看手"升级到"看得见靶子"：

- **全场景覆盖**：静态点击（甩枪/点靶）、动态点击（移动靶）、切换（转火）、追踪四大类，任何地图无需预先配置
- **零训练、零模型文件**：基于封闭三形状先验（KovaaK 靶只有球/竖胶囊/人形）+ 颜色假设集自动发现靶色，纯传统 CV，确定性可复现
- **弹着点级测量**：每枪打中/打偏、偏移的方向与角度、转火耗时、跟靶误差曲线——这些是纯输入数据永远给不了的
- **诚实降级**：每局带质量门（靶色置信度、击杀配对率、覆盖率），看不懂的局（如烟花粒子场景）自动退回纯输入分析，绝不编造视觉结论

### 🧠 证据驱动的 AI Coach

接上你自己的 LLM Provider（OpenAI 兼容协议）后：

- **讲解基于事实**：Coach 通过受控工具读取分析证据（指标、事件、分布），而不是靠模型瞎猜；术语遵循社群校订的对照表（甩枪/停稳/转火，不说 flick/settle）
- **@ 视频回看**：讲解里说"这 3 秒注意看你的修正"，点 @ 标记直接跳到录像对应时刻
- **训练闭环**：从诊断生成训练计划 → 跟踪完成情况 → 复测对比进步
- **本地知识库**：内置瞄准理论、KovaaK 数据解读、外设（鼠标/鼠标垫）选择等结构化知识，Coach 讲课前必须先查库、查不到就明说
- **长期视角**：跨局趋势、历史对照是 Coach 的本职，不需要你翻旧记录

### 🔒 本地优先的隐私模型

- 单用户桌面应用，无账号、无云端、无遥测
- 所有数据（局、分析、对话、知识）以 JSON 文件存在本机 `%APPDATA%`
- 唯一的外部流量是你自己配置的 LLM Provider——发什么、发给谁，完全由你决定

## 界面一览

三个日常表面，没有仪表盘堆砌：

- **Coach**：对话 + 当前训练计划 + 「本次讨论」挂载的局（点开即看该局录像）
- **History**：每局的时间线、分析状态、录像回放
- **分析工作台**：诊断结论 / 视频播放器 / 数据视图三栏，从任一指标下钻

## 技术架构

| 层 | 技术 | 要点 |
|---|---|---|
| 桌面壳 | Tauri (Rust) | 窗口采集、Raw Input、本地令牌、子进程编排 |
| 后端 | Python FastAPI | 分析任务队列、KovaaK 摄取、确定性分析管线 |
| Coach 运行时 | Node sidecar（Pi 基线） | LLM 对话编排、受控工具、JSONL 会话持久化 |
| 视觉 | OpenCV 传统 CV | 三形状分类 + 颜色假设集，无神经网络 |
| 前端 | Next.js | Coach / History / 分析工作台 |
| 数据 | 本地 JSON 文件 | 无数据库、无云依赖，人可读可备份 |

数据合同采用"冻结合同"治理：关键 schema 显式版本化（`*.v1`），升级必须走版本演进而非静默改写。
