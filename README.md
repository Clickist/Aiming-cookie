# Aiming Cookie

**本地运行的 FPS 瞄准 AI 教练。** 面向 KovaaK's FPS Aim Trainer 的认真训练者：打完一局，它已经看完了你的鼠标轨迹、对局遥测、击杀记录和录像，能告诉你哪里出了问题、偏了多少度、下次练什么。

不打分、不玄学——所有证据来自你自己的机器，分析与数据都留在本地。

---

## 为什么做这个

市面上的瞄准工具只有两种：**数据面板**（给你 KPS/命中率，但不说为什么）和**感觉派教学**（说得出为什么，但看不到你的数据）。

Aiming Cookie 的立场是：**教练必须先看证据，再开口。** 它把一局训练拆成四路证据，用确定性管线测量、用视觉管线"看"靶子，最后让大模型教练拿着这些事实讲课——每一句判断都能追溯到具体数据，讲不到的就是不知道。

## 核心能力

### 🎯 毫秒级遥测——核心差异点

分数面板只会告诉你"打得怎么样"，遥测能回答"场面和手到底发生了什么"：

- **全自动采集**：KovaaK 击杀表、成绩计数、对局遥测、窗口录像随局自动入库，打完即得；源文件指纹校验，改过一个字节都会被发现
- **靶子的完整真值**：每个靶子何时出现、在哪、怎么移动、多大、何时被消灭——全部来自游戏自身数据，不是从画面里估算；尺寸直接取自场景定义
- **Windows Raw Input**（opt-in 授权）：1ms 采样率的操作系统级真实鼠标信号——不是游戏内插值的近似值
- **真值直接算指标**：每发子弹的命中/脱靶、击杀瞬间的角度误差、跟靶误差曲线、转火耗时——由"靶子真值 + 原生输入"直接导出，命中口径以遥测为权威，角度测量精确到亚度级
- **同一条毫秒时间轴**：所有证据互相对齐，Coach 指到的每一秒都对得上画面

### 👁️ 通用视觉分析——看得见靶子的回退与补充

遥测不可用的对局（旧存档、特殊场景），视觉管线能从录像里独立重建证据：

- **全场景覆盖**：静态点击（甩枪/点靶）、动态点击（移动靶）、切换（转火）、追踪四大类，任何地图无需预先配置
- **零训练、零模型文件**：基于封闭三形状先验（KovaaK 靶只有球/竖胶囊/人形）+ 颜色假设集自动发现靶色，纯传统 CV，确定性可复现
- **行为细节**：准星修正动作的形态、转火轨迹等画面层证据，可与遥测交叉印证
- **诚实降级**：每局带质量门（靶色置信度、击杀配对率、覆盖率），看不懂的局（如烟花粒子场景）绝不编造视觉结论

### 🧠 证据驱动的 AI Coach

接上你自己的 LLM Provider（OpenAI 兼容协议），或使用 Aiming Cookie 官方托管服务（内测期）后：

- **讲解基于事实**：Coach 通过受控工具读取分析证据（指标、事件、分布），而不是靠模型瞎猜；术语遵循社群校订的对照表（甩枪/停稳/转火，不说 flick/settle）
- **@ 视频回看**：讲解里说"这 3 秒注意看你的修正"，点 @ 标记直接跳到录像对应时刻
- **训练闭环**：从诊断生成训练计划 → 跟踪完成情况 → 复测对比进步
- **场景直达**：一键搜索 KovaaK 官方场景库（17 万+ 场景），推荐场景经你确认后直接拉起 KovaaK 开练
- **本地知识库**：内置瞄准理论、KovaaK 数据解读、外设（鼠标/鼠标垫）选择等结构化知识，Coach 讲课前必须先查库、查不到就明说
- **长期视角**：跨局趋势、历史对照是 Coach 的本职，不需要你翻旧记录

### 🔒 本地优先的隐私模型

- 单用户桌面应用：局、分析、对话、知识全部留在本机，以 JSON 文件存储（`%APPDATA%`），人可读、可备份
- 自动的联网只有两类：版本更新检查、KovaaK 版本适配表获取——都不涉及你的训练数据
- 其余联网由你决定：模型流量只发往你自己配置的 Provider（或内测期的官方托管服务）；诊断包只在你手动点「上传」时才会发送

## 界面一览

三个日常表面，没有仪表盘堆砌：

- **Coach**：对话 + 当前训练计划 + 「本次讨论」挂载的局（点开即看该局录像）
- **History**：每局的时间线、分析状态、录像回放
- **分析工作台**：诊断结论 / 视频播放器 / 数据视图三栏，从任一指标下钻

## 技术架构

| 层 | 技术 | 要点 |
|---|---|---|
| 桌面壳 | Tauri (Rust) | 窗口采集、Raw Input、本地令牌、子进程编排 |
| 后端 | Python FastAPI | 分析任务队列、KovaaK 摄取、确定性分析管线 |
| Coach 运行时 | Bun/Node sidecar | LLM 对话编排、受控工具、JSONL 会话持久化 |
| 视觉 | OpenCV 传统 CV | 三形状分类 + 颜色假设集，无神经网络 |
| 前端 | Next.js | Coach / History / 分析工作台 |
| 数据 | 本地 JSON 文件 | 无数据库，人可读可备份 |

数据合同采用"冻结合同"治理：关键 schema 显式版本化（`*.v1`），升级必须走版本演进而非静默改写。
