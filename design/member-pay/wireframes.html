AC 会员全流程线框稿 v3

design/member-pay · 2026-09-20 · 明主题 · v3 修订（按真实 Onboarding 骨架）：会员＝Onboarding「连接模型服务」里的一个 Provider 选项（连通才放行），主界面无锁定态、无任何充值弹窗，余量只显示百分比；落地页右上角新增账号入口。订阅制（连续包月）+ 退款按剩余比例。双档：基础 ¥10/约120轮 · 高频 ¥30/约400轮

⓪流程总览

Onboarding（必须连通 Provider 才放行） 步骤1 连接模型服务──▶ ① 选「Aiming Cookie」＝登录/注册 → 订阅 → 自动配好 ┆或┆ 选「自定义 Provider」＝BYOK（现状不变）──连接成功──▶ 步骤2 → 主界面
主界面（进来即已连通，无锁定态） ② 左下角账号 chip（百分比余量）──剩20%──▶ ③ 将尽横幅──用尽──▶ ④ 发送时 inline 提示（升级/加速包/等下期）
付费与管理（网页侧，客户端只做入口跳转） ⑤ /pay 购买页（订阅双档）──▶ Stripe Checkout 订阅──▶ ⑥ 成功 / ⑥b 未完成付款 / ⑥c 处理中──▶ ⑦ 管理订阅 / 取消 / 退款申请
订阅周期与落地页 ⑧ 扣款提醒 / 失败 dunning──彻底失效──▶ ⑨ 连接断开提示（重新订阅即恢复） ⑩ 落地页右上角 登录/头像 → 账号中心（⑪ P2）
铁律（点点 0920 定）：①禁止任何形式的充值弹窗——付费引导全部是页面内常驻元素；②余量只显示百分比，不出现金额；③Onboarding 未连通 Provider 不放行进主界面——所以主界面里不存在"锁定态"，只存在"用尽"与"连接断开"。
