design/member-pay · 2026-09-20 · 明主题 · v3.2 修订：①选「Aiming Cookie」后弹网页完成登录+订阅，deep-link 回客户端自动配置（客户端内不做登录/付费）；②左下角用户卡片点击 → 右侧主区域整体切换为用户中心（带 ← 返回，对齐训练历史页导航模式）；③额度用尽只提示事实+指引账户/BYOK，主消费页面零商业化；④删除将尽提醒（百分比常驻，用户自己会看）；⑤落地页按真实导航加右上角账号入口。订阅制（连续包月）+ 退款按剩余额度比例。

⓪流程总览

Onboarding（连通 Provider 才放行） 步骤1 连接模型服务──▶ 选「Aiming Cookie」──弹网页──▶ 网页：登录/注册 → 选档订阅（Stripe）──deep-link 回客户端──▶ token 自动注入 · 连接成功──▶ 继续 → 主界面
主界面（无弹窗、无商业化元素、余量只显示百分比） 左下角用户卡片（余量 %）──点击──▶ 右侧区域＝用户中心（← 返回）──额度用尽──▶ 发送时 inline 提示「本期额度已用完」+ 指引账户/BYOK
网页侧（付费与管理） ⑤ /pay 购买页（订阅双档）──▶ Stripe Checkout──▶ ⑥ 成功 / 处理中 / 未完成──▶ ⑦ 管理订阅 / 取消 / 退款申请──彻底失效──▶ ⑨ 连接断开提示（重订即恢复）
落地页 ⑩ 右上角：未登录＝「登录」；已登录＝头像下拉 → 账号中心（⑪）
铁律：①客户端内不出现登录表单与订阅选择（弹网页，deep-link 回）；②禁止任何充值弹窗；③主消费页面不谈钱不谈升级，只说事实；④余量只显示百分比；⑤未连通 Provider 不放行主界面。
