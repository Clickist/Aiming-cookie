## 工程侧状态机（订阅）

- Stripe Checkout（subscription mode）→ `invoice.paid` webhook → accounts 发放本期额度（基础 625 万 / 高频 1875 万 quota）→ 注入用户 new-api 令牌。
- 取消 = cancel at period_end；扣款失败 = Stripe Smart Retries ~7 天，期间不中断；彻底失效 → 客户端显示⑨，重订即恢复连接（无需重走 Onboarding）。
- 升级档位：默认次周期生效；立即补差为可选（待定）。
- 百分比 = 剩余额度 ÷ 本期初始额度。

## 待点点拍板

1. **档位名**：暂「基础档/高频档」。
2. **升级生效**：次周期（线稿默认）vs 立即补差。
3. **加速包**（④的一次性加购 ¥10/约120轮）：做不做。
4. **退款下限条款**：如「已使用超 50% 不再部分退」要不要加。
5. 客服邮箱地址（退款申请 mailto 用）。
