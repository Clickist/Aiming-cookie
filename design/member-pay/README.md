## 状态机要点

- 承诺物=额度（quota 余额）；**轮数一律为估算展示**（综合价 ¥0.106/轮换算），页面不承诺轮数。
- 客户端本地会员态来自 JWT + ac-gateway 查询；未登录时 ② 的支付按钮置灰引导登录。
- BYOK 用户永不弹①⑧⑩（自带 Key 走另一路）。

## 异常矩阵

| 场景 | 表现 | 兜底 |
|---|---|---|
| 点充值没付款（Stripe 页取消） | ⑤挽回页 | 可继续开通或返回，无状态残留 |
| 点充值后直接关闭 Stripe 标签（无回跳） | 客户端维持①拦截态 | 等价⑤，重进即为全新流程 |
| 已扣款但额度未到账（webhook 延迟） | ④处理中页 | 手动刷新；Stripe 会话 id 已记录可人工补发 |
| 未登录点支付 | ②支付按钮置灰 | 引导登录后回② |
| 额度对不上（用户觉得少） | ⑪逐笔消耗明细 | 明细含时间/轮数/扣减 |
| 到期不续费 | ⑩续费拦截 | 教练历史/设置永久保留 |
| 已生效订阅退款 | ②FAQ 声明不退款 | 人工例外走客服 |
| 同档重复购买 | 规则待定 | 建议=延长有效期+叠发额度 |

## 待点点拍板的待定项

1. **档位名**：线框暂用「基础档/高频档」，可换饼干梗（小饼干/饼干桶）或纯「标准/畅聊」。
2. **升级生效规则**：基础→高频，当月补差立即升？还是次月切换？
3. **耗尽加购规则**：⑧「立即再购」=叠加一份当月额度（立即生效）——确认这个规则。
4. **Payment Link 模式**：一次性月购（无自动续费，靠⑨提醒手动续）还是 Stripe 订阅（自动扣款+取消入口）？线稿按「月购+提醒续费」画的，若是订阅模式②⑪要加「取消自动续费」实义。
5. 邮件模板两枚（到期提醒/耗尽提醒）：P3，文字稿后补。
