2. **主界面无锁定态、无任何充值弹窗**——能进主界面就说明 Provider 已通。付费引导全部为页面内常驻元素：左下角账号 chip、耗尽 inline 提示条。将尽横幅已删除（百分比常驻，用户自己会看）。
3. **余量只显示百分比**（剩余÷本期发放），不出现任何金额/轮数。
4. **落地页右上角账号入口**：未登录=「登录/注册」按钮；已登录=头像+邮箱下拉。
5. 订阅制（连续包月）+ 退款政策：未使用（0 消耗）14 天全额退；已使用按剩余额度比例退；取消=周期末止。

## 商业规则终稿（0919 深夜拍板，已全部定稿）

| 规则 | 内容 |
|---|---|
| 档位 | **Standard ¥10/月**（120轮当量）· **Plus ¥30/月**（400轮当量，单轮价低10%） |
| 加油包 | ¥10/包 · **永不过期** · 须有效订阅才能买 · **余额归零才能买下一包** · 断订后余额可烧完 |
| 扣减顺序 | 先订阅池 → 订阅空了自动落加油包池 |
| 余量显示 | **单条百分比**＝当前池（订阅条绿橙红分档；加油包池独立百分比）；用户中心显示两池全貌；④用尽提示＝双池皆空才触发 |
| 升级 | **＝自动退旧订新**：按剩余比例折算旧档退款抵扣新档，差价当场结清；新周期从升级日起算、额度满上（显示 100%）；随时可点 |
| 降级 | **不存在**。想下去只有退款一条路 |
| 取消 | 周期末止；已取消未到期＝按钮双态（同位置变「恢复自动续费」），客户端横幅「将于 X 到期」 |
| 退款 | 订阅+加油包**两笔一起**按比例清算、不留余额，退完即免费用户；邮件申请→人工 1~3 天→Stripe 部分退款 |
| 邮件 | **不发任何到期/额度提醒邮件**；扣款失败通知 Stripe 自带；Resend 模板工作项删除 |
| 退出登录 | 不打回 Onboarding：配过 BYOK 自动 fallback；没配过则主界面照常进、Coach 置灰+「去设置连接」 |

统一原则一句话：**用户付过钱的永远不清零不折损**（加油包不过期、退款全清算、升级折算，全是这条的面相）。

## 工程侧状态机（订阅）

- Stripe Checkout（subscription mode）→ `invoice.paid` webhook → accounts 发放本期额度（Standard 625 万 / Plus 1875 万 quota）→ 注入用户 new-api 令牌。
- 升级＝Stripe 立即切档 + proration 按比例折算差价（`proration_behavior` 原生），额度发放侧「退旧折算+发新满额」。
- 取消 = cancel at period_end；扣款失败 = Stripe Smart Retries ~7 天（自带邮件），期间不中断；彻底失效且加油包有余额 → 客户端显示「订阅已到期 · 正在使用加油包余量」，双池皆空才显示⑨断开提示。
- 百分比 = 剩余 ÷ 当前池初始发放量（升级/购包即新池新分母，无杂凑数）。
