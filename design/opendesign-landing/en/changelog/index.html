Release notes

Every change to Aiming Cookie, in one place.

v1.4.2

Latest2026-10-06
  • NewStartup is now visible: a launch screen with logo and progress appears first, slow starts explain why, and failures come with clear guidance
  • FixedFixed the app freezing and crashing on startup failure: it now stays open with a one-click diagnostics export
  • FixedFixed sessions failing outright when camera frames were missing during processing

v1.4.1

2026-10-06
  • NewSession motion-data processing now carries forward: re-processing a session keeps its previously successful result instead of reworking it from scratch
  • FixedFixed sessions flipping from "processed" back to "failed" when processed again
  • ImprovedA few borderline sessions that were previously rejected outright now process successfully

v1.4.0

2026-10-05
  • NewMotion analysis for target-switching scenarios: switch transition time (from one kill to re-acquiring the next target) and switch path efficiency, measured from ground-truth telemetry rather than estimation
  • FixedFixed analyses getting stuck on "queued" and never finishing: static-clicking scenarios (e.g. 1wall 6targets small) now complete on the first try, and previously stuck analyses recover on retry
  • ImprovedSmoother first-run onboarding: the coach gets straight to training instead of circling
  • FixedThree membership-page fixes: plan-card colors in dark/light themes, continuous-billing wording now matches the actual monthly purchase, and the account card no longer renders misaligned
  • FixedMotion-analysis time alignment fixed: all motion metrics now align to the real round window — previously the window started about 8 seconds early, cutting off the end of each round and mixing in pre-round data
  • FixedTarget track segmentation fixed: kill counts now match the game's official stats line by line — previously targets were over-segmented, inflating kills by nearly half and distorting tracking metrics
  • ImprovedData-quality transparency: analyses with imperfect data now flag which metrics deserve caution, and the coach says so plainly instead of presenting compromised numbers as reliable readings
  • ImprovedScenario classification fix: switching-style scenarios (such as Tile Frenzy 180) are now analyzed as switching, with switch cadence and path readings of their own instead of tracking-style yardsticks

v1.3.9

2026-10-05
  • NewTraining-record processing is now visible at a glance: rows show what is still being processed and how many runs are queued, and a notification pops up when everything is ready
  • FixedTracking-style motion analysis is dramatically faster and no longer fails intermittently: no more long waits ending in a score-only fallback - crosshair-to-target adherence and error metrics now arrive within seconds, and repeated analysis of the same run gives consistent results
  • FixedFixed some new users getting stuck on sign-in onboarding: the one-time credential from the browser sign-in is no longer lost — it is retried automatically if the app isn't ready, and reopening the app picks the earlier sign-up back up
  • FixedMore resilient startup: page-load failures now retry instead of leaving a rare blank screen, and launching a second copy no longer blanks the first window
  • FixedMotion-layer diagnostics fixed: tracking-style scenarios now produce crosshair-versus-target motion analysis instead of being skipped, and one faulty round no longer drags down the rest of a session
  • FixedFixed “larger + slowed” style scenarios failing to process their data: targets carried over from the previous run are no longer mistaken for on-screen debris, so these scenarios process and analyze normally again

v1.3.8

2026-10-04
  • FixedNew-user funnel fixes: the official Aiming Cookie option now leads the provider list; the client polls automatically after sign-in instead of waiting forever; the trial CTA appears on its own once quota lands — no restart needed
  • FixedDevice handoff validity extended from 10 to 30 minutes, leaving ample time for email verification
