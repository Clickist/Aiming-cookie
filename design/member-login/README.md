### 对 AC 的映射结论（两轮合计）

- **登录页/Onboarding（最核心的启示）**：把「登录会员」做主 CTA 的同时，**明示免费出路**——AC 版对应：主按钮「登录 / 注册」+ 次入口「先不用，直接 BYOK 免费用」。登录是增强不是门槛。
- **AC 设置页账号区** ≈ Open Design 设置页的绿色账户横幅：「登录 Aiming Cookie——解锁云端 AI 教练与跨设备同步」+ 登录按钮，插在引擎/账号设置上方。
- **AC BYOK 设置区** ≈ BYOK 配置页：Key 输入（带显隐）+ Base URL + 拉取模型/测试 + 绿成功/红错误双反馈条。
- **账号中心三态卡** ≈ 云控制台概览页「订阅横幅 + 黑色余额条」结构：金卡（会员）/灰卡（免费 BYOK）/未登录，横幅右侧升级按钮。
- **购买页 /pay** ≈ 登录页分栏骨架收窄 + 单一套餐卡（¥10/月），不需要四列。
- **定价区** ≈ 定价弹窗「价格卡 + FAQ」两段式塞进落地页区块；「免费版永久可用」写在 Free 卡大字位。
- **客户端左下角** ≈ workspace 切换器 + 余额 chip 合体：账号行（头像+打码邮箱+会员角标）点击弹小卡片；**未登录态常驻**（变「登录以解锁云端教练」）。
- 引擎（云会员/本地/BYOK）与账号登录分两层设计，任何状态下都不锁死用户进产品的路。
