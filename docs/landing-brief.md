# Aiming Cookie 落地页内容 Brief（草稿）

**建立 2026-08-19 · 状态：草稿，待点点审阅**
**本 brief 只定义内容与信息架构。视觉（风格、版式、配色、字体、禁则）全部交由 Open Design 自由发挥，本文不提供视觉要求。**

## 目标与受众

- **受众**：大陆为主、希望用真实训练输入获得客观诊断的认真 KovaaK's 玩家。
- **目标**：5 秒说清"这是什么"，然后驱动下载。
- **一句话定位**：基于物理 + 运动学的 KovaaK's 瞄准诊断 + AI 教练（桌面应用，免费）。

## 全页主线

**「分数会骗人」→ 我们能让你更真实、敏锐地感受到自己的进步和改善。**

全页论证沿三条优势线展开（相对人类教练 / 社区教练）：

1. **数据精度**：一手原始数据 vs 看录像猜
2. **知识密度**：碎片化社区知识整合成体系、且与你的数据对应 vs 个人经验碎片
3. **关系形态**：无限耐心的专属私教 vs 有限的付费课时 + 社交压力

## 内容块

### 1. Hero

- 主线：分数会骗人。文案候选：
  - A：「分数会骗人，数据不会。」
  - B：「你的进步，分数看不见。」
  - C：「别让分数定义你的瞄准。」
- 副文案方向：一手数据 + AI 教练，免费。
- CTA：下载 Windows 版。

### 2. 对照：看录像 vs 一手数据

- 社区教练的常规方式：玩家发训练录像，教练凭录像里的行为凭经验分析。
- 我们的方式：读取一手原始数据——鼠标操作数据（Raw Input）+ 录屏 + KovaaK Stats/Performance。
- 核心信息：一手原始数据比纯看视频的分析精准一个量级。

### 3. 无感采集

- 后台自动采集：鼠标操作数据 + 录屏 + KovaaK 自带 Stats/Perf；用户零操作，练完切回应用直接看。
- KovaaK's 本身缺少录屏 / 回放功能，我们顺带补足了它。
- 覆盖范围（可一句话带过）：static/dynamic clicking、continuous tracking、target switching。

### 4. 核心块：分数会骗人 + 长期训练循环（合并）

全页最需要被记住的块，传达两个层次：

1. **分数与能力是两回事**：分数和当天状态强相关；能力指标相对独立。
   - 场景 A：分数没涨，但能力指标在进步——你确实在进步，只是分数看不出来。
   - 场景 B：状态爆种分数暴涨，但能力没有变化——状态不是能力。
2. **长期训练循环**：分析 → 训练计划 → 复测 → 进步可见。社区教练是一次性服务（付一节课看一个 VOD），我们是常驻。

块的核心信息：**我们能让你更真实、敏锐地感受到自己的进步和改善**（复测看的是能力指标，不是分数）。

### 5. 指标与科学

- 运动学公平指标：decel_frac / SPARC / linearity / throughput 等；学术锚点（Balasubramanian 2012 / Fitts / Novak 2002）。
- 手健康标语条（独立版面）：「别人只关心你点得准不准，我们也关心你的手痛不痛。」

### 6. Coach 三支柱

1. **体系化知识**：散落国内外的碎片化社区瞄准文档 / 教学视频 → 整合为体系化系统，并与你的一手数据对应上。
2. **外设经验**：外设与鼠标选择建议，来自外设博主的选择经验（署名口径：外设博主）。
3. **专属私教**：零压力——低分不会嘲笑你、更不会劝你放弃；耐心用白话讲清瞄准概念；不计时间成本，时间只属于你一个人；毫无保留，并且鼓励你。
   - punchline 候选：「在这里，菜不是问题，不练才是。」

### 7. 演示

- Coach 讲解真实一局的视频演示，必须带字幕 / 文字步骤。
- **素材依赖**：需要真实训练 + Coach 讲解的录屏（待确认来源，未解决）。

### 8. 下载与收尾

- 免费产品；Windows 桌面应用。
- 一行须知：Coach 需要自备 LLM provider（免费的是产品；模型费用属于用户与所选 provider 的关系）——不写会有安装后落差。

## 文案口径约束

- **免费、暂不开源**：不出现 GitHub / 开源字样（PRD 口径待更新确认）。
- **外设建议只说"经验建议"**：不写商城、购买推荐或联盟（商业关系是后续阶段的事）。
- **不设独立信任块**；如需兜底，最多在下载区一句"数据只留在你的电脑上"（待点点定）。
- 不写"Powered by XXX"式具体模型品牌——用户自选 Provider。

## 演示素材录制清单

### 落地页素材（优先，短）

| # | 素材 | 时长 | 说明 |
|---|---|---|---|
| 1 | **招牌演示**：Coach 讲解真实一局 | 30–90s | 落地页第 7 块；必须带字幕 / 文字步骤 |
| 2 | **分数 vs 能力对比**：同一个人、两种日子的指标对比 | 15–30s | 核心块；可以是产品内对比图动图或短录屏 |
| 3 | **无感采集**：KovaaK 练完 → 切回应用看到自动切好的 Run 与回放 | 15–30s | 对应"无感采集"块 |

### 应用内 onboarding 教程（次优先，长）

- Provider 连接、开启自动采集等分步教程；
- 与落地页素材可共用录制母带，但剪辑口径不同（教程要完整步骤，落地页要短）。

### 通用录制要求

- 固定一个稳定场景（按要讲的内容选），用真实训练数据；
- 横屏 16:9、稳定帧率；旁白 / 字幕后期加，不依赖环境音；
- 画面避开 Settings 里的 API key、文件路径、个人 Steam 信息；
- UI 仍在快速迭代（v0.1.x）：第一版素材只做设计与剪辑占位，正式发布前用稳定版重录。
